# Retail Sales Analytics Dashboard

## 📊 Project Overview

Retail Sales Analytics is a data analysis and business intelligence project built to analyze retail transaction data and identify sales, product, customer, and country-level performance.

The project uses Python for data inspection and cleaning, MySQL for data analysis, and Power BI for interactive dashboard visualization.

---

## 🎯 Project Objective

The main objectives of this project are:

- Analyze overall retail sales performance
- Understand monthly sales trends
- Identify top-performing products
- Analyze sales by country
- Identify high-value customers
- Calculate total revenue and orders
- Calculate Average Order Value (AOV)
- Analyze quantity sold
- Build a professional Power BI dashboard

---
